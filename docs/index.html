Battle-Tested Caddy Architectures


      

        

          

            proxy
            Most Popular
          

          
Unified Reverse Proxy

          

            Single port handling HTTP and WebSockets together. Perfect for Node.js, Express, Fastify, Next.js, and CareCall.
          

          npx caddy-template proxy domain.com 3000
        


        

          

            ws-split
            Microservices
          

          
Split HTTP + Dedicated WS

          

            Directs /ws* to a dedicated WebSocket daemon (e.g. :8080) and all other paths to an HTTP app (:9011).
          

          npx caddy-template ws-split domain.com 9011 8080
        


        

          

            static
            Static Sites
          

          
Static File Server

          

            Configures vars.root and Caddy's high-speed file_server handler for documentation or SPAs.
          

          npx caddy-template static cli.domain.com /usr/share/caddy
        


        

          

            multi-host
            Domain Aliases
          

          
Multi-Domain Binding

          

            Binds apex domain and subdomains (e.g. domain.com and www.domain.com) to one target.
          

          npx caddy-template multi-host domain.com,www.domain.com 9328
